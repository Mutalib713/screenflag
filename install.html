screenflag

A responsive review station that opens inside the page you are already looking at. Resize, step through your routes, measure each screen, and flag the broken ones with a note.

Install

  1. Make sure your bookmarks bar is showing — Ctrl + Shift + O, or Ctrl + Shift + B to toggle it.
  2. Drag this button up onto the bar:

screenflag

Dragging is required — clicking it on this page does nothing useful. Then open any site you want to review and click the bookmark.

What it does

RoutesSave a route list per site. Your GMSA routes wait for you on GMSA; Perry's wait on Perry's.
WidthsPresets, plus drag the right edge to any width. The true CSS width is always on screen.
ScaleFit / 100% / 75% / 50%. Shrinks the picture only — the page still lays out at its real width.
Device / full pageScroll inside a fixed height like a phone, or grow the frame to the whole document.
MeasureSideways overflow (naming the element), tap targets under 44px, text under 12px, nested scrollers.
FlagStar a screen and add a note. It captures the route, width, time and findings for you.
ExportRoutes and flags as JSON for a teammate, or a markdown summary to paste into chat.

What it cannot do

It cannot measure a page on another domain. Browsers do not let one site read another's page. It will still display it, and it will say so plainly rather than reporting a false all-clear.

It cannot run where a site blocks injected scripts. GitHub and X do this. Your own apps almost never do.

It is not a real device. It changes the viewport, not the browser engine, the touch input or the GPU.

Sharing what you found

Open Flags → Export. There are two buttons, for two different people:

Copy summary For anyone. Plain text they can read with nothing installed — paste it into WhatsApp, a group chat or an issue. Each line carries the page, the width, your note and the element at fault:
- **Members** @320px — header pushes the page sideways on a small phone overflow +9px: a.flex-1.md:flex-none "person_addAdd New Member"
Copy JSON For someone who also has screenflag. They paste it into Import and get your exact routes and flags, and can click straight back to any flagged screen at the width you flagged it at.

To share the tool itself, send someone this page. Updates arrive on their own — the bookmark fetches the current file every click, so nobody re-copies anything.
